The IBM Scrum Project was the final capstone project for the IBM IT Scrum Project certificate.

The Scenario: 
You and your team will work to develop a business application (App) for the Mega City Department of Transportation (DOT). Traffic congestion has increased to a level where the DOT wants to provide an App that Mega City users can use to plan and manage their daily commutes effectively. The Project Charter and Project Roadmap will define the specifics, key goals, and objectives.
Next, we did a Stacey Analysis, which determines the optimal method for planning and executing project objectives. Stacey’s Analysis suggests implementing objectives using either traditional project management methods or adaptive Scrum methods, depending on the situation. The Mega City Commuter App project is a hybrid project. Your team will evaluate the objectives in the Project Charter and apply a Stacey Analysis in a hands-on lab to determine which aspects of the project to accomplish using Scrum.
