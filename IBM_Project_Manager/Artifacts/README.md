**Capstone Project:**

Project Management Professional Certificate (PC) Capstone course. This course provides you the opportunity to apply the project management knowledge and skills learned in the previous eight courses of the Project Management Professional Certificate (PC).

Module 1 introduced a comprehensive scenario and project initiation activities to include development of a project charter and stakeholder register. 

We started with the project scenario: Acme Health Innovations (AHI) is a major provider of advanced skin care products. The goal of this project is to develop an application (app) that provides real-time marketing data to address marketing shortfalls. Three scenario documents are provided, including an overview of AHI, an approved business case to create a formal project, and a Stacey diagram analysis that defines how seven key project objectives will be planned and executed.

The project scenario provides an overview of AHI and the purpose of the project. The scenario defines the key business contacts, the requirements for the functionality of the new app, the benefits that the app should provide, the improvements to the AHI marketing processes that the app will ensure, the benefits to the various stakeholders, and an initial cost estimate for the project.

The project business case defines the business need for the project, the project rationale, and the project implementation strategy. It is an approved business case that allows for the development of a project charter.

The Stacey diagram analysis shows the project goals and recommends planning and implementing the project with both predictive (waterfall) and adaptive (Agile/Scrum) methods.

Module 2 introduced project planning activities that included the development of a Work Breakdown Structure (WBS), network diagram, high-level budget, quality management plan, communications management plan, and a risk register. Here is an overview of Module two:
•	I built a predictive project management plan using the project scenario, business case, Stacey diagram analysis, project charter, and stakeholder register developed in Module one.
•	 I created a WBS, network diagram, and high-level budget using the documents previously outlined.
•	I also learnt how to create a quality management plan, communications management plan, and risk register using the documents presented in the course.
